# NEX Picture Design Logic

## Layout

- Desktop content should feel cinematic but controlled. Use a 16:9 hero/video frame as the widest visual reference.
- Main page sections should not visually exceed the hero frame width. Current reference tokens:
  - `--nex-site-max: 1320px`
  - `--nex-section-max: 1160px`
- Use generous vertical spacing, but avoid oversized type that makes the page feel like a landing page template rather than a production studio site.

## Surfaces

- Prefer soft white cards with a very light blue radial glow in one corner and a subtle blue stroke.
- Avoid the old single blue line at the bottom of cards. It reads like a template component and should be replaced by:
  - white/ice surface,
  - `rgba(0, 97, 255, 0.08-0.12)` radial gradient,
  - thin `rgba(0, 97, 255, 0.1)` border,
  - soft blue-gray shadow.

## Dark Backgrounds

- The footer and dark CTA areas may use a deep charcoal/navy background with faint diagonal light streaks.
- Keep this as a NEX treatment, not a copied footer layout:
  - use asymmetric panels where the capability card and contact card do not mirror the competitor's logo-left/social-right grid,
  - keep the footer compact: it should feel like a closing utility block, not a second hero section,
  - avoid a direct logo-left/social-right/service-address grid copied from competitors,
  - use a blue horizontal divider as a brand accent,
  - add soft blue radial light in the upper corner.

## Copy Tone

- NEX Picture should sound like a business video production partner, not only a studio.
- Prefer language about B2B outcomes: trust, proof, sales enablement, recruitment, search, and stakeholder confidence.
